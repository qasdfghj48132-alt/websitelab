ЛАБОРАТОРНАЯ РАБОТА № 2 — ВАРИАНТ 44
Тема: гостевой дом «Уютный берег» (Bed & Breakfast).

Файлы проекта:
- index.html — главная страница;
- about.html — информация о гостевом доме;
- catalog.html — номера и услуги;
- price.html — прайс-лист;
- contacts.html — контакты, карта и форма запроса;
- styles.css — все стили сайта;
- images/ — SVG-иллюстрации сайта;
- js/site.js — скрипт формы бронирования.

Открытие:
Откройте index.html в браузере. Для публикации загрузите все файлы и папки проекта на статический хостинг.

Примечание: проект учебный. Контактные данные и цены демонстрационные. Адрес карты задан по учебному макету.

Контактный адрес для учебного проекта: Москва, ул. Тверская, д. 7. Карта на странице контактов настроена на этот адрес. Телефон и электронная почта указаны как учебные контактные данные.
